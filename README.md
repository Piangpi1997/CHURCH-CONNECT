# CHURCH-CONNECT
CHURCH CONNECT — CMF Church အတွက် Member Management၊ Digital Member ID &amp; QR၊ Departments၊ Events၊ Giving၊ Ministry၊ Mission၊ Media၊ Volunteers၊ Reports နှင့် AI Assistant တို့ကို တစ်နေရာတည်းတွင် ချိတ်ဆက်စီမံနိုင်သော လုံခြုံပြီး အနာဂတ်တွင် Multi-Church / Multi-Campus အထိ ချဲ့ထွင်နိုင်သည့် Digital Church Management Platform ဖြစ်သည်။ ⛪
